# Mirath — the Quranic inheritance system, formalized

The fixed-share inheritance law of Surah An-Nisa 4:11–12 and 4:176 as a
total algorithm over the rationals — fixed shares, residuary ('asaba)
distribution, 'awl over-subscription reduction, radd surplus return —
with a general proof that every distribution sums exactly to the estate,
and the classical worked cases as kernel-checked tests. Ticket #46
(milestone 1). Pure Lean at pin v4.34.1; zero sorries; axioms only
propext / Classical.choice / Quot.sound.
