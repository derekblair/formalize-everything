Conventions: the book inner product is **linear in its first argument**, conjugate-linear in its second. Mathlib's complex inner product is conjugate-linear in its first argument. Thus the book `(x,y)` must be translated as Mathlib `inner ℂ y x`, or all formulas must explicitly account for the swap. `T` is the circle with Haar/Lebesgue probability measure `dt/(2π)`; coefficients are `ĉ(n)=∫f(t)exp(-int)dt/(2π)`. The book uses `ℓ²(A)` for arbitrary index sets, including uncountable ones.

## Statement defects and scope discrepancies

1. **4.7, pp.78–79.** The criterion is stated for a set M⊆V using only binary addition closure and scalar closure. Empty M satisfies both vacuously but is not a vector subspace, since it has no zero. Corrected criterion adds M nonempty or 0∈M. The definition of a vector space already supplies zero, but that does not repair the backward implication of the printed criterion for an arbitrary set M. Similarly, the bound-by-1 non-example requires nonempty S. Formalization should prove a counterexample or clearly label these additional hypotheses.
2. **4.20, p.87.** Scan checked visually (`inventory-page86-87.png`). Ambient poset is explicitly all open subsets of the plane; there is no exclusion of empty set or the plane. For ordinary open discs with positive finite radius, neither empty set nor the full plane is such a disc, yet both are comparable with every disc. Thus the disc chain is not maximal. A suitable corrected maximal chain adds both endpoint sets; a counterexample alone meets the brief's disclosure branch. This is not an OCR artifact.
3. **5.7 and 5.13.** Their literal formulations require nonempty X. The immediately preceding 5.6 explicitly excludes empty X only when deducing a nonempty intersection. The book's metric-space definition in §1.4 says X is a set with metric axioms, without a nonempty premise (cross-check: https://djvu.online/file/NKmAEzkLVs8Io, body near §1.4). Empty complete metric space has no isolated points and empty set is countable, dense, and Gδ. Treat as an explicit empty-space edge correction, not failure of ordinary nonempty Baire theory.
4. **5.3 and 5.21 unit-sphere suprema.** Zero spaces have empty unit spheres. Use nonnegative extended supremum with bottom 0, or split trivial/nontrivial spaces and disclose the convention. Do not casually invoke real least-upper-bound properties on the empty set.
5. **Ticket #38 headline mentions closed graph.** In this third-edition printed text it occurs in **Chapter 5 Exercise 16, p.114**, not among 5.1–5.25. Both ticket and brief exclude exercises. Therefore closed graph is out of scope under the explicit v1 exclusion; report this discrepancy instead of inventing an extra numbered body node.
6. **A numbered node is not necessarily one theorem.** Particularly 4.5, 4.7, 4.15, 4.19, 4.23–4.26, 5.11, 5.21–5.24 contain multiple substantive assertions. Proving just a headline theorem must not be reported as the whole node complete. 5.1 and 5.5 are purely narrative; 5.18 is a numbered proof of 5.16. Inventory counts should retain these and distinguish inspected narrative from proof coverage.
