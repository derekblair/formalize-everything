## Representation and fidelity disclosures

1. **In-book Riemann mapping route (`14.8`/`14.9`/`14.15`) rather than Mathlib's partial `RiemannMapping.lean` ([SCOPING-H-19-20.md](SCOPING-H-19-20.md), Label `R1`):**
   - Pinned Mathlib's `Mathlib/Analysis/Complex/RiemannMapping.lean` provides only an injective holomorphic map *into* `ball 0 1` without surjectivity (`R1`), which is insufficient for `20.2`. `RudinRCA/Chapter20.lean` does **not** import `RiemannMapping.lean`; instead, `theorem20_2` (`L526`) reduces `Ω = S² \ E` via `Chapter14.moebiusHomeomorph` and `Chapter13.theorem13_11` to a bounded simply connected region containing `0`, applies the book's own surjective Riemann mapping and extremal derivative theorems (`Chapter14.theorem14_8`, `Chapter14.theorem14_9`, `Chapter10.theorem10_33`), and derives the conformal radius bound `1/4 ≤ α r < r` via the omitted-value diameter theorem `Chapter14.theorem14_15` (`‖w₁ - w₂‖ ≤ 4`).
2. **Hazard 20.2a — Kernel diagonal domain correction ([SCOPING-H-19-20.md](SCOPING-H-19-20.md), Hazard 2, p. 387):**
   - Rudin's printed second estimate `|Q(ζ, z) - (z - ζ)⁻¹| < 1000 r^2 / |z - ζ|^3` quantifies over `z ∈ Ω` and `ζ ∈ D` without stating `z ≠ ζ`. Because `E ⊂ D` is compact and `D = ball z₀ r` is open, `D \ E` is nonempty, so the diagonal `z = ζ ∈ D \ E` genuinely occurs, and under Lean's totalized division `0⁻¹ = 0` the right-hand side `1000 r^2 / 0^3 = 0` makes the strict inequality `‖Q ζ ζ‖ < 0` impossible.
   - `node20_2_diagonal_counterexample` (`L480`) formally proves `(ball z₀ r \ E).Nonempty` and refutes the literal unguarded diagonal quantification for every `g : ℂ → ℂ` and `b : ℂ`.
   - `theorem20_2` (`L526`, with plane-complement form `theorem20_2_compl` at `L1088`) proves the uniform first estimate `‖g z + (ζ - b) * (g z) ^ 2‖ < 100 / r` for **all** `z ∈ Eᶜ` and `ζ ∈ ball z₀ r` (including `z = ζ`), the everywhere-valid polynomial-multiplied bound `‖(z - ζ) ^ 3 * Q(ζ, z) - (z - ζ) ^ 2‖ < 1000 * r ^ 2` for all `z ∈ Eᶜ, ζ ∈ ball z₀ r`, and the kernel estimate `‖Q(ζ, z) - (z - ζ)⁻¹‖ < 1000 * r ^ 2 / ‖z - ζ‖ ^ 3` explicitly guarded by `z ≠ ζ`.
3. **Hazard 20.2b — Holomorphy at `∞` ([SCOPING-H-19-20.md](SCOPING-H-19-20.md), Hazard 3, p. 387):**
   - Because `Ω = S² \ E` contains `∞`, `DifferentiableOn ℂ g Eᶜ` alone omits holomorphy at infinity. Both `theorem20_2` (`L526`) and `theorem20_2_compl` (`L1088`) explicitly establish holomorphy at `∞` with value `0`: `Tendsto g (Bornology.cobounded ℂ) (𝓝 0)` **and** `DifferentiableAt ℂ (fun w : ℂ => if w = 0 then (0 : ℂ) else g w⁻¹) 0` on an open punctured-disc neighborhood `{w | ‖w‖ < δ}` (`w⁻¹ ∈ Eᶜ` for `w ≠ 0`).
