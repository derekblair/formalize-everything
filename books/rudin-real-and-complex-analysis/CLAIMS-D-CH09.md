## Conventions and exact adapter equations

Let `c=(sqrt(2*pi))⁻¹`, and define Rudin's measure `m = ENNReal.ofReal c • volume`. For any ordinary function f,

- `F_R(f)(t) = c * F_M(f)(t/(2*pi))`, where `F_M = 𝓕` is Mathlib's transform with kernel `exp(-2*pi*I*x*t)` and unscaled volume.
- `F_R_inv(f)(x) = c * F_M_inv(f)(x/(2*pi))`.
- `f *_R g = c • (f *_M g)`.
- `normLp_m(f) = c^(1/p) * normLp_volume(f)` for finite p (appropriate eLpNorm/ENNReal formulation first).

An alternative mathematically convenient adapter is coordinate dilation: put `s=sqrt(2*pi)`, `U f(u)=f(s*u)`. Change of variables gives `U : Lp(m) ≃ Lp(volume)` isometric, and `U(F_R f)=F_M(U f)`. Consequently conjugating the existing Mathlib L2 isometry by U produces the exact Rudin L2 transform, once compatibility with integrals is proved. This avoids silently changing either norms or kernels. The analogous convolution identity is `U(f *_R g)=(Uf)*_M(Ug)`.

For generic `VectorFourier` lemmas one can instead use `Real.fourierChar` and pairing `L(x,t)=x*t/(2*pi)`, with measure m. That works directly for continuity, bounds, translation, and Fourier pairing; the specialized inversion/L2 lemmas still need normalization transport.

Poisson kernel: `H(t)=exp(-|t|)`, `h_lambda(x)=sqrt(2/pi)*lambda/(lambda^2+x^2)`, for lambda>0. Thus `h_lambda dm` is the usual Cauchy probability density `lambda/(pi*(lambda^2+x^2)) dx`. Printed pp.179 and 183 were visually checked; images retained at `evidence/ch09-page179.png` and `evidence/ch09-page183.png`. In particular 9.2(d) is **conjugate-reflection**, not reflection alone.

## Detailed reusable proof routes and caveats

1. **A.e. inversion / L1 uniqueness.** `VectorFourier.integral_bilin_fourierIntegral_eq_flip` is a Fubini pairing identity for arbitrary integrable f,g. Schwartz Fourier inversion is exact. Pair f against a Schwartz Fourier transform and transfer F to f; if Ff=0, every smooth compactly supported test integral vanishes. `MeasureTheory.Lp.ker_toTemperedDistributionCLM_eq_bot` (Distribution/TemperedDistribution.lean:216) proves injectivity via `ae_eq_zero_of_integral_contDiff_smul_eq_zero`. For inversion, establish that the distribution represented by `F_R_inv(F_R f)` equals that represented by f, then use local-integrable test uniqueness. This is a proposed mathematical route, not a theorem already proved in the chapter.

2. **L1∩L2 compatibility.** `Lp.fourier_toTemperedDistribution_eq` and `Lp.fourierInv_toTemperedDistribution_eq` exist. To identify classical Fourier integrals for a general L1∩L2 f, one still has to prove their distributional compatibility using the same Fubini pairing. `Lp.fourierTransform` in FourierTransform.lean is an L1-to-bounded-continuous-function map; it is not the L2 equivalence in LpSpace.lean. The identically named notations overload different domains and do not by themselves prove compatibility.

3. **Poisson approximation.** `MeasureTheory.convolution_tendsto_right` has a hypothesis that supports shrink to zero. Its hypotheses fail for h_lambda. Rudin's proof by scaling plus domination is the appropriate approach. For Lp convergence the integral bound is a new formal lemma; `ConvolutionExists.of_memLp_memLp` and `enorm_convolution_le` give conjugate-exponent pointwise bounds, not Young's Lp norm bound.

4. **Convolution Banach algebra.** Analysis/Convolution.lean has `Integrable.ae_convolution_exists` (288), `AEStronglyMeasurable.convolution` (521), `Integrable.integrable_convolution` (527), `convolution_congr` (495), `convolution_flip`/`convolution_symm` (683/690), `integral_convolution` (890), `convolution_assoc'`/`convolution_assoc` (901/927). Associativity pointwise requires convergence hypotheses; quotient-level associativity should be a.e. using these hypotheses. The total Bochner integral convention returns zero on divergent integrands, so arbitrary pointwise associativity is false and must not be asserted.

5. **Nonunital homomorphism bound.** Do not use default `Unitization` norm blindly: Normed/Algebra/Unitization.lean assumes `RegularNormedAlgebra`. The separate UnitizationL1 file avoids that extra assumption and provides `WithLp.unitization_norm_inr`, `WithLp.unitizationAlgEquiv`, completeness, a normed algebra instance, and norm of 1 equal to 1. Compose `Unitization.lift phi` with this equivalence and invoke `AlgHom.norm_apply_le_self` at the embedded a.
