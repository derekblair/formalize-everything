# Indexed edges to actual closed polygonal paths

`PolygonalCyclePackage.lean` combines `BalancedCycles.lean`, `PolygonalConcat.lean`,
`CyclicVertices.lean`, and `SegmentIntegralBridge.lean`. Those declarations must occur earlier
in the aggregate; this scratch file does not pretend they are installed project modules.

The main theorem `balanced_polygonal_cycle_package` chooses a finite collection `C` and actual
closed paths `D s` **before** quantifying over the continuous integrand. Every input edge index
belongs to a unique component, and each component's edge enumeration is injective and covers
its assigned edge set. The paths lie in the supplied support set. For every continuous-on-support
complex function, all path integrals exist and their total equals the original indexed segment sum.
Identical geometric segments with distinct indices retain their multiplicity.

The new `IsPolygonalPath` predicate is generated by segment paths, constant paths, finite
concatenation, and endpoint casts. It supplies an explicit finite polygonal construction. A bridge
from this predicate to `Chapter13.IsPiecewiseC1Path` is separate work; it is not silently assumed.
